# 拾光旅行 · AI 旅行规划工具

> 输入目的地、天数、预算、偏好，AI 帮你生成一份可执行的分天行程，并按行程动线推荐住宿区域，一键跳转主流平台查价订房。

## 产品定位

旅行前做攻略最耗时的两件事：① 把零散信息拼成一份「哪天去哪、吃什么、住哪」的行程；② 挑酒店要在多个 App 之间来回切。拾光旅行把这两件事合一：AI 先规划行程，再顺着每天的动线推荐住哪个片区，并给出各平台查价入口。

## 核心功能

| 模块 | 说明 |
|------|------|
| 行程生成 | 输入目的地 + 天数 + 预算 + 偏好，AI 流式生成分天行程（含时间、景点、说明、类别） |
| 预算统筹 | 人均总预算含机酒，可自填往返大交通 / 住宿金额，AI 先扣机酒再分配剩余 |
| 小红书参考 | 支持贴小红书链接或文字要点，AI 自动剔除软广/营销内容后融合 |
| 住宿推荐 | 按行程动线推荐 1~3 个住宿区域（就近原则 + 预算档位 + 选房建议） |
| 多平台跳转 | 每个住宿区域一键跳转 10 个订酒店平台查价 |

## 预算逻辑

- 预算是**整个行程的人均总预算**（含往返大交通 + 全程酒店）。
- 用户可自填「往返大交通」「住宿预算」两项固定开销，AI 直接从总预算扣除，剩余部分再分到每天的餐饮、门票、交通、娱乐。
- 预算滑条两端**可重合**，表示「固定金额」。
